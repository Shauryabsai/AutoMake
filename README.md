# AutoMake
AutoMake is a desktop market research and digital product creation platform built for creators and entrepreneurs.
​Purpose of the Application:
AutoMake helps users discover market opportunities, validate product ideas, and organize digital product launches from a single workspace.
​How AutoMake Uses Google Ads Data:
AutoMake connects to the Google Ads API (Keyword Planner) to retrieve search volume estimates, competition metrics, and keyword ideas for user-entered topics. Data is fetched strictly for the authenticated user's own Google Ads account to power internal market analytics inside the AutoMake desktop application. AutoMake uses Google Ads API access solely for read-only keyword research and does not create, modify, or run paid advertising campaigns.
